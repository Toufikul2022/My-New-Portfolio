# My New Portfolio

Personal portfolio website of Toufik Ul Islam — a single `index.html` file, no build step.

## Editing

All content (name, titles, projects, journey, stack, links) lives in the `SITE` object near the bottom of `index.html`. Put images or videos next to `index.html` and reference them from `SITE`, e.g. `img: "project1.jpg"`.

## Viewing

Open `index.html` in a browser, or visit the GitHub Pages site once it is enabled.
